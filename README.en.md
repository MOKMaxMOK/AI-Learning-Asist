## Usage Guide
![alt text](image_for_readme\image.png)`
### 1. Subject Binding

Each chat window is bound to one subject. This affects the learning analytics data for that window.
![alt text](image_for_readme\image-1.png)

---

### 2. Chat

Supports file uploads. Chat bubbles render Markdown formatting.
![alt text](image_for_readme\image-9.png)

---

### 3. LLM Binding

Go to Settings from the bottom of the hamburger menu. The first item is LLM Binding, which supports multiple model providers or a custom Base URL (must be OpenAI-compatible). Bindings can be deleted.
![alt text](image_for_readme\image-4.png)

You can also clear all stored changes with one click.
![alt text](image_for_readme\image-6.png)

---

### 4. Analytics

Includes subject analysis, study time tracking, and a daily checklist. (More features coming later.)
![alt text](image_for_readme\image-13.png)

#### 4.1 Subject Analysis

Displays your learning situation as a pie chart, based on the subjects studied in Chat.
![alt text](image_for_readme\image-14.png)

Click a subject in the pie chart to view its knowledge point heatmap, which tracks mastery status.
![alt text](image_for_readme\image-18.png)

Click a specific knowledge point to view its wrong-answer statistics.
![alt text](image_for_readme\image-22.png)

#### 4.2 Study Time Tracking

Timeline is zoomable.
![alt text](image_for_readme\image-23.png)

#### 4.3 Daily Checklist

Reminds you to study.
![alt text](image_for_readme\image-26.png)
